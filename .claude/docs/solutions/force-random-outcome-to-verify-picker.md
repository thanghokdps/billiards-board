# To verify a weighted random pick, force one option to 100% and confirm it wins

A random outcome can look correct on one spin by chance.
Set one option's weight to 100%, run a spin, and confirm that option wins.
Then remove a participant mid-run and confirm later rounds still complete, since removal is the usual edge case.

Evidence: "Đặt Bổ 100% rồi quay 1 lượt: Bổ trúng."
