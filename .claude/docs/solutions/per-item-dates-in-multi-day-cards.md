# Show each item's own date when a grouped card spans several days

A single date in a card header reads as applying to every row, so a row from a later day looks like an earlier day.
When the items span days, print the date on each item's row.
Keep the header date only when all items share one day.
Render both the single-day and the multi-day case before calling the fix done.
