# Report animation smoothness as median and worst frame time, not by eye

Sample frame times in the browser during the animation.
Report the median and the worst frame, for example 16.7ms median and 33ms worst.
Note which device the numbers come from, since a desktop run does not prove a phone is smooth.

Evidence: "Trên Mac, một lượt quay có trung vị 16,7ms mỗi khung hình, chậm nhất 33ms."
