# New match formats must reuse the sibling formats' row layout and labels

When a new format is added to a shared list or row, match the layout and labels of the existing formats instead of inventing a separate one.
Keep the same structure (avatar beside name, one shared score display, same win/loss labels) and apply any label added to one format to all of them.
Compare the new row against the existing rows on the same screen before showing it to the user.
